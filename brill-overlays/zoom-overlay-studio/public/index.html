    Running Brill Overlays inside Zoom

    You're in browser preview mode. Everything you design here is saved and will appear in Zoom once the app is installed:

    1. Run node server.js and expose it over HTTPS (e.g. ngrok http 3000).
    2. In the Zoom App Marketplace → Develop → Build App, create a General app and enable the Zoom App surface for Meetings.
    3. Set the Home URL to your HTTPS URL, and add it to the Domain allow list.
    4. Under Zoom App SDK, add the APIs: runRenderingContext, closeRenderingContext, drawParticipant, clearParticipant, drawImage, clearImage, drawWebView, clearWebView, postMessage, onMessage, getRunningContext, getUserContext, getVideoState, onMyMediaChange, onRenderedAppOpened.
    5. Set the OAuth redirect URL to https://YOUR-URL/auth, then use Local Test → Add app.
    6. Join a meeting, turn on your camera, open Apps → Brill Overlays, and press Go live in Zoom.

    Full instructions are in README.md. No Zoom app yet? Use Clean output + OBS Virtual Camera as a fallback.
